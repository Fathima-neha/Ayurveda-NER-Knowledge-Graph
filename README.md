# 🌿 Ayurveda NER & Knowledge Graph

## 📖 Overview

This project demonstrates Named Entity Recognition (NER) for Ayurveda text using SpaCy.

The model identifies important medical entities such as herbs, diseases, symptoms, and health benefits. The extracted entities can later be used to build an Ayurveda Knowledge Graph.

---

## 🚀 Features

- Data preprocessing
- Custom SpaCy NER model
- Entity extraction
- Relationship extraction (coming soon)
- Knowledge Graph generation (coming soon)
