
# 🌿 Ayurveda NER & Knowledge Graph

## 📖 Project Overview

This project focuses on extracting important information from Ayurveda text using Natural Language Processing (NLP).

The project identifies important entities such as herbs, diseases, symptoms, and benefits, and then connects these entities to build an Ayurveda Knowledge Graph.

This project was developed as a learning project inspired by my internship work in AI and Knowledge Graph development.

---

## 🎯 Objectives

- Extract Ayurveda entities using Named Entity Recognition (NER)
- Identify relationships between extracted entities
- Build a Knowledge Graph
- Visualize entity relationships
